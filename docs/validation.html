Validation Cases

The solver is tested against a growing set of validation cases spanning external aerodynamics, internal flows, urban microclimate, and multi-body interactions.

Each case is an experiment: a different geometry, boundary condition, and Reynolds number designed to stress a specific capability of the solver, from smooth curved boundaries to turbulent separation. Every run produces velocity fields, quantitative validation against experimental or benchmark data, and a physical discussion of what the results mean.
