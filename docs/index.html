AK-Vortex: High-Performance C++ Lattice Boltzmann CFD Solver

How does air flow around a plane wing, a high-rise building, or a racing car? To predict this without expensive physical wind tunnels, engineers use Computational Fluid Dynamics (CFD) to simulate air as millions of interacting particles. Commercial solvers like ANSYS are powerful tools, but their complexity hides away the underlying physics. To better understand CFD at the implementation level, I set out to build a solver from scratch.

AK-Vortex is a custom 2D CFD solver built from scratch in C++ using the Lattice Boltzmann Method, packaged into a desktop application with a geometry editor, real-time flow visualization, and parameter study tools. Built with Rust and C++.

Desktop Application Walkthrough

Step 01

Application Overview

Launch the app and tour the interface layout: sidebar panels, canvas viewport, and solver log. The feature-tree sidebar organizes geometry, solver parameters, and visualization controls in a familiar CAD-style hierarchy.

▶
Screenshot: Application Overview Full interface with sidebar, canvas, and solver log
Step 02

Geometry Editor

Draw circles, rectangles, and polygons directly on the canvas. Design a 4-digit NACA airfoil with parametric camber, thickness, and rotation controls. Drag to reposition, resize via handles, and detect shape collisions automatically.

✎
Screenshot: Geometry Editor Drawing obstacles with parametric NACA airfoil controls
Step 03

Simulation Control

Configure grid size, Reynolds number, and inflow velocity. Press Run and watch the solver log stream in real time as the C++ backend executes the LBM timestep loop via FFI. The progress bar tracks completion while the solver runs at full native speed.

⚙
Screenshot: Simulation Running Solver log streaming with progress bar
Step 04

Flow Visualization

Render velocity magnitude, pressure, or vorticity fields. Toggle streamlines and quiver overlays. Probe any point to read local u, v, rho, p, and omega values. Watch the flow develop frame-by-frame from rest to steady-state.

🌊
Screenshot: Flow Visualization Velocity contour with streamlines and field probe
Step 05

Parameter Studies & PINN Surrogate

Run parameter sweeps across Reynolds numbers and geometry configurations. Compare two simulations side-by-side. Launch a GCI grid convergence study from the same interface.
